# Changelog

## 0.2.0 — Portfolio template foundation

- Added Persian and English language switching with RTL/LTR document direction.
- Added a shared locale provider and centralized site configuration.
- Removed the standalone projects route; project details now open in an accessible modal.
- Added bilingual project case-study content: overview, challenge, approach, outcome, and stack.
- Centralized articles, experience, and skills in reusable data modules.
- Added sitemap, robots metadata, and a custom not-found page.
- Added commercial release and content-model documentation.
