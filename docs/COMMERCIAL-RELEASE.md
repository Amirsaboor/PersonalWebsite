# Commercial release and customization notes

## Included
- Static Next.js portfolio with GitHub Pages export.
- Shared language state for English/Persian and RTL/LTR document direction.
- Modal-only project details.
- Shared site configuration at `src/data/site-config.js`.
- Project records at `src/data/projects.js`.

## Before selling
- Replace every sample identity, organization, testimonial, contact address, and social URL.
- Replace external sample photography with images you own or have licensed for redistribution. An image being publicly reachable does not grant template redistribution rights.
- Bundle a Persian font with a license that permits web embedding and redistribution, or document that buyers must provide their own font.
- Add a commercial license that clearly distinguishes template resale from use in one end product.
- Test the actual deployed static export under the configured base path.
- Add screenshots for desktop/mobile and both languages.
- Add a support and update policy, version number, changelog, and a clean demo site.

## Not included by design
No admin panel, CMS, database, authentication, server API, or contact form backend. The template is configured by editing source files and rebuilding.
